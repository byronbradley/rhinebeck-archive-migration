# Rhinebeck Historical Society archive migration proposal

I proposed moving the society's digital catalog and available scans to Internet
Archive. The catalog listed about 13,258 records when I reviewed it, including
both individual items and collections.

The proposal is awaiting review at the November 2026 board meeting. I haven't
started writing the migration scripts or uploading records.

## The plan

I'd start with a small batch for the society to review. That means converting
the catalog fields, matching records to scans, and checking for items already
on Internet Archive before uploading anything twice. Catalog numbers and the
original date descriptions would stay with each record.

The test batch would also establish how to represent text-only records and
collections on Internet Archive. Text-only records would be included, with
scans added later where available.

After the test batch is approved, I'd work through the rest in batches. I'd
compare the uploaded files and catalog fields with the source, check previews,
page order, and downloads, and keep a list linking catalog numbers to their
new URLs. Missing files and unresolved records would go on a separate list
for review.

## What needs checking first

I need to confirm which catalogs are included, get the available database
export and media files, and check how those files match the records. The
society also needs to confirm publication permissions, account access, and
who will review the test batch.

The initial estimate is 4–6 weeks at about 20 hours per week once materials
and access are available. That needs to be checked against the actual data
and the time taken by the test batch.

The [work log](docs/work-log.md) records the proposal and next steps. Source
exports, archive media, and credentials are kept outside this repository.
